开关 1 一间房，开关 2、3 一间房；按原走法走线

这一版按房间摆、按原走法走线，不做灯盒串联：开关 1 单独在房间一，管房间一的灯 1 和新增灯（并联、同开同关）；开关 2、开关 3 在房间二，两地双控房间二的灯 2。每组灯的火线、零线、地线同管走：灯 2 的 N、PE 跟着开关链走——经 C 段到开关 2 盒、经 E 段到开关 3 盒、再经 B2 段到灯 2 盒，不从灯盒那边绕。根数按原走法：A 段 3 根，B1 段 3 根，D 段 3 根，C 段 3 根（L、N、PE），E 段 4 根（T1、T2、N、PE），B2 段 3 根（L2′、N、PE），共 6 段管、无 F 段，灯 1 盒与新增灯盒只在开关 1 这一组内过线，不与灯 2 盒相连。进线走法不变：电箱下口出 → 地面 → 上墙 → 开关 1 盒下口进、上口出；两个开关不在同一间房，C 段默认走地面。点任意一个开关（按钮或 3D 里的面板），灯会亮灭，下方同步显示那个盒子的接线图。

每段管里到底几根线

根数以系统图为准：WL1 全回路 2.5 mm²，管统一 JDG20。按原走法共 6 段管、无 F 段：每组灯的 L、N、PE 同管走，灯 2 的 N、PE 随开关链（C → E → B2）到灯 2 盒，3 个灯盒不跨组串联。布局按房间：房间一 = 开关 1 盒 + 灯 1 + 新增灯；房间二 = 开关 2、3 盒 + 灯 2，两开关不在同一间房，C 段默认走地面。进线（A 段）和 C 段走地面，开关盒一律下口进、上口出去灯；系统图标注为 WC/CC，本图按你定的走法把进线改为地面敷设（FC），组价时 A 段（及 C 段）按地面内敷设计。

原走法省线只在同组内：主干 A 段只走一套线供全回路，开关 1 的两盏灯共用 B1 一套线、在灯 1 盒过线接第二灯（D 段仍是 L1′、N、PE 共 3 根），这是同一开关组内的共用。跨组不再串联：灯 2 的 N、PE 不走灯盒，改随 C 段（3 根）、E 段（4 根）、B2 段（3 根）到灯 2 盒。省不了的也写明：双控的 T1、T2 两根联络线一根不能少，每盏灯的 PE 不能省，两路受控火线不能合并。

双控这一路，哪根线带电会变

C 段里的 L 一直未受控带电；E 段里哪根联络线带电，取决于两个双控开关当时的掷向 —— 在开关 3 处把灯关了，开关 2 那边再拨一下，联络线又会带电。所以检修开关 2 盒、开关 3 盒或灯 2 之前，必须先断 WL1 空开，不能靠"灯是灭的"判断没电。

每个盒子里面分别怎么接

点任意一个开关，下方就显示那个盒的接线图；点「放大开关 X 盒内部」还能在 3D 里看盒内放大示意。各盒接法：

  1. 开关 1 盒（分线点 · 下进上出）：A 段从下口进盒，L 分两支 —— 一支进开关 1、出 L1′ 从上口去灯 1 盒（一根 L1′ 带两灯）；另一支经 C 段去开关 2 盒。N、PE 在端子里各分两路：一路从上口经 B1 段去灯 1 盒，另一路随 C 段去开关 2 盒；PE 另加尾线接盒体。
  2. 灯 1 盒（过线点）：B1 进来的一套线在端子并接：一支接灯 1，另一支经 D 段去新增灯盒。两灯并联在 L1′ 与 N 之间，同开同关，不能串联。新增灯盒是这一组的末端，不再往灯 2 盒连管连线。
  3. 开关 2 盒（双控 A · 房间二）：C 段进来的 L 进双控开关 2 的 COM；开关的 L1、L2 端出 T1、T2 两根联络线，连同端子直通的 N、PE 一起经 E 段去开关 3 盒（E 段共 4 根）。
  4. 开关 3 盒（双控 B · 房间二）：T1、T2 进双控开关 3 的 L1、L2 端，COM 出 L2′，连同对接直通的 N、PE 一起从上口经 B2 段去灯 2（B2 段共 3 根）。开关 2、开关 3 必须都用单联双控（单刀双掷）开关，普通单控开关接不出双控。
  5. 双控判据：两开关同掷 T1 → 亮；同掷 T2 → 亮；一个 T1 一个 T2 → 灭。任一处拨动，都翻转灯 2 的状态。
  6. 地线规矩不变：PE 每个盒里还要一根尾线接盒体接地螺丝。PE 不进开关、永不断开、不能省。
三条铁规矩：接头只能在开关盒、灯盒里做，管内不许有接头；N 与 PE 在箱外绝不能混接，否则漏保误跳或失去保护；双控联络线 T1、T2 两头要做对应标记，接反了两个开关的掷向关系就对不上、排查很费劲。

顺着电流读一遍

层总电箱来线进 ALss1：L、N 过总开关 MCB-C32A/2P，再过 WL1 分路 C16A/2P + RCD 30mA（L、N 一起穿过漏保互感器，漏电差值超 30mA 即同时断 L、N）；PE 不过任何开关，直达 PE 排。出箱 3 根线从箱体下口出、走地面、上墙、从开关 1 盒下口进盒后分两路：一路 —— 开关 1 合上 → 电流走 L1′、从开关 1 盒上口出 → 灯 1 盒：一支进灯 1，一支经 D 段进新增灯，两灯并联、同亮同灭 → 沿共用 N 回箱内 N 排。另一路 —— 未受控 L 经 C 段到开关 2 盒、进双控开关 2 的 COM，按掷向走联络线 T1 或 T2、经 E 段到开关 3 盒；只有开关 3 也掷向同一根联络线时才接通，电流从开关 3 的 COM 出 L2′、从开关 3 盒上口出 → 灯 2 → 沿 B2、E、C、A 的 N 回箱内 N 排。所以灯 2 在开关 2、开关 3 两处都能开关，进门开、到另一头关，就是这种接法。
